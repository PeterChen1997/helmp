# 第三方数据 / Third-party data

## Unicode CLDR 注释与 Unicode Emoji 数据

`src/providers/emoji/data.tsv`（Emoji 与符号的中英文名称、关键词、排列顺序、是否支持肤色）由
`script/gen-emoji.py` 从以下数据生成，随 Helmp 一起编译：

- Unicode CLDR 49.0.0 注释（`cldr-annotations-full`，英文 `en`、简体中文 `zh`）
- Unicode Emoji 18.0 `emoji-test.txt`

表末尾的 Mac 按键符号（⌘ ⌥ ⌃ ⇪ ↩ ⌫ ⌦ ⎋ ⇥ ␣ ）及其名称是 Helmp 自己补充的，不属于 CLDR。

annotations (English and Simplified Chinese) and the Unicode Emoji 18.0 `emoji-test.txt`. These data
files are distributed under the Unicode License v3, reproduced below.

## 汇率 / Exchange rates

货币换算使用欧洲央行（ECB）每日公布的参考汇率（`eurofxref-daily.xml`），运行时下载并缓存在本地数据目录，
不随应用分发。ECB 说明这些汇率仅供参考。

Currency conversion uses the European Central Bank's daily euro foreign exchange reference rates,
downloaded at runtime and cached locally (not bundled). The ECB publishes them for information
purposes only.

## 时区 / Time zones

时区规则来自 IANA Time Zone Database（公有领域），由 `chrono-tz` crate 编译进应用。

Time-zone rules come from the IANA Time Zone Database (public domain), compiled in via the `chrono-tz` crate.
