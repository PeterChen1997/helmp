Plugin Center插件中心

Every plugin here is reviewed by hand before it is listed. When you install one, Helmp checks each file against its SHA-256. New plugins stay off until you turn them on, and Helmp lists their permissions for you to approve first. 这里的每个插件都由维护者人工审核后才上架。在 Helmp 里安装时，会逐个校验文件的 SHA-256；装好后默认关闭，启用前先列出权限让你确认。

Submit your plugin提交你的插件

The easiest way is to let a coding agent do it with you. Everything goes through a pull request that the maintainer reviews by hand. 最省事的办法是让 coding agent 陪你一起做。所有插件都通过 PR 提交，由维护者人工审核。

With Claude Code or Codex用 Claude Code 或 Codex

  1. Connect Helmp's MCP server (helmp mcp) to Claude Code or Codex. 在 Claude Code 或 Codex 里接入 Helmp 的 MCP 服务（helmp mcp）。
  2. Ask it to write the plugin. It checks the result with helmp plugins validate first. 让它帮你写插件。它会先用 helmp plugins validate 校验。
  3. It always asks you before submitting. Once you agree, it opens a pull request to PeterChen1997/helmp-plugins with your own GitHub account through the gh CLI. 提交前它一定先问你。你确认后，它用你自己的 GitHub 账号（gh CLI）向 PeterChen1997/helmp-plugins 开 PR。
  4. The maintainer reviews it by hand, then it shows up here. 维护者人工审核通过后，插件就会出现在这里。

By hand手动提交

Run this in a terminal. It prints what it is about to do; add --yes to actually do it. 在终端里运行下面的命令。它会先打印将要做什么，加上 --yes 才真正执行。 

helmp plugins submit <plugin-dir>
